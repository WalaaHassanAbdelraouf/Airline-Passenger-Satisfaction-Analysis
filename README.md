# Airline-Passenger-Satisfaction-Analysis

## Project Overview
This project explores an airline passenger satisfaction dataset using Exploratory Data Analysis (EDA). The main goal is to understand passenger satisfaction levels, discover patterns in customer behavior, and identify the services that are most related to customer satisfaction.

## Dataset Used
The project uses the [Airline Passenger Satisfaction dataset](https://www.kaggle.com/datasets/teejmahal20/airline-passenger-satisfaction), which contains passenger survey data about travel experiences and airline services.

## Tools & Technologies
- Python
- Pandas & NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Workflow
1. **Data Exploration:** Examined the dataset, data types, and descriptive statistics.
2. **Data Cleaning:** Removed unnecessary columns and handled missing values using median imputation.
3. **Data Visualization:** Created charts to explore passenger demographics, travel preferences, and satisfaction levels.
4. **Exploratory Analysis:** Investigated the relationship between passenger satisfaction and different airline services.

## Key Insights
- Business Class passengers generally showed higher satisfaction levels than Economy passengers.
- Loyal customers showed higher satisfaction compared to disloyal customers.
- Inflight Wi-Fi, entertainment, online booking, and onboard services were associated with passenger satisfaction.
- Younger passengers showed lower satisfaction levels compared to older age groups.

## Recommendations
We should:
  - Improve service quality and passenger experience in Economy Class.
  - Focus on improving important services such as inflight entertainment, Wi-Fi, and online booking.
  - Consider different passenger preferences when improving airline services.
